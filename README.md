## Review method

1. Start with the governing architecture at a recorded SHA.
2. Inspect other repositories only via their root `CONTRACT.md`, unless access is separately approved.
3. Record evidence separately from inferences and proposals.
4. Obtain explicit approval before changing governing architecture, implementation or other repositories.
5. Record formal adoption only after the relevant governing changes are accepted; retain this workspace as review evidence.

This repository does not override any accepted ADR. In particular, ADR-0012's 50-line composition budget is currently mandatory.
